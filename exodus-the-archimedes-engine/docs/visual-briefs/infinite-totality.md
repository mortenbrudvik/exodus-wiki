## Physical / design cues (research)

- Shell fuselage custom-manufactured by a Lidon astroengineering firm
- Form: a **cone whose base flares into a sphere** (closed casing)
- Material: **ultrabonded fibre** hunted from Lidon’s ruined geo-ring
- The *Arcadia’s Moon* (golden geodesic sphere + eight interior ovoids) flies *inside* the shell
- Shell can split in half and hinge open; book 2 shows the ship docking while the shell closes around it
- Not a freighter, not a navy hull — continuous camouflage casing
