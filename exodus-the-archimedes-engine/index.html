Main Page

Spoilers: This wiki assumes you have finished Exodus: The Archimedes Engine. Articles contain full spoilers.

This is a personal full-spoiler reading companion for Peter F. Hamilton’s 2024 novel Exodus: The Archimedes Engine — a space-opera set in the far-future Centauri Cluster and a narrative prequel for the Exodus game universe. Use it to look up people, places, factions, technology, timeline, and plot after (or while) reading.
